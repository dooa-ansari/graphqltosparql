**Masters Thesis**
Thema : "Processing of mapping an existing SparQL Open Data endpoint to GraphQL endpoint without losing data integrity"

**Motivation**
The rigid structure of SPARQL queries and the need to comprehend data schemas make it difficult for frontend or application end users to utilise open data effectively. Moreover,  Small-level organisations usually do not have enough budget or resources to afford courses on semantic technologies. The timeline of projects can also be tricky in the case of RDF, since writing the SPARQL queries can be difficult. The situation becomes more difficult for independent working students, trying to create researched projects by utilising open data portals, can find it almost impossible to utilise data.
